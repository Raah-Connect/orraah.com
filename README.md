# orraah.com

Marketing and commerce site for Orraah, built with Next.js.

## Development

1. Install dependencies:

```bash
npm install
```

2. Copy env template and fill in values:

```bash
cp .env.example .env.local
```

3. Run locally:

```bash
npm run dev
```
